## Overview

Arena-X SA is a mobile-first web platform for the South African market. Players enter skill-based tournaments against other real players, with matches, results and prizes handled inside one platform. It combines a real-time multiplayer game, a social layer and an operator dashboard.

Two games are supported:

- **Ludo Royale:** a full multiplayer Ludo game built into the platform, with rules enforced on the server.
- **Dream League Soccer 2026:** 1v1 matches played in the DLS app, with results confirmed through the platform using check-in, score reporting and screenshot evidence.

## The problem

South African mobile gamers have no structured, secure place to compete head-to-head. Competition today tends to happen informally in chat groups, with no match management, no dispute process and no shared leaderboard. Arena-X SA brings matchmaking, verification, results and community into a single mobile-friendly platform.

## Key features

### Games
- **Ludo:** 56-square board, 3D animated dice, square-by-square piece movement, bonus rolls, practice mode and tournament mode.
- **Dream League Soccer 2026:** match creation, team name and online code exchange, check-in, multi-screenshot score reporting, disputes and forfeit handling.

### Tournaments
- Create and join tournaments from a live lobby.
- Real-time updates as players join.
- Automatic winner payout inside the platform wallet.
- Time-limited matches.

### Community
- Global chat and tournament room chat.
- Friends with online status.
- Clans with roles and management tools.
- Player and clan leaderboards.
- Real-time notifications and a live activity feed.
- Referral programme with WhatsApp sharing and QR code.

### Accounts and trust
- Email sign-up and sign-in.
- Age check (18+) and identity document verification before deposits or withdrawals.
- Profiles with game statistics.

### Admin command centre
- Live platform overview.
- User, tournament and dispute management.
- Identity verification review queue.
- Finance tools for manual deposit and withdrawal handling.
- Analytics, platform settings and broadcast notifications.
- Chat, clan and referral moderation.

### Installation
- Installable as a Progressive Web App.
- Direct Android app download.
- Built-in install guide for different devices and browsers.
